```bash
pnpm add -D smellcheck
```

Node.js 20+. The package is [`smellcheck`](https://www.npmjs.com/package/smellcheck) on npm. Markdown you point an agent at. Nothing scans the tree. v1 has no CLI.

No package? [Install the skill](/skill) as a folder.

## Agent setup

1. Copy `node_modules/smellcheck/rules/cursor.mdc` to `.cursor/rules/smellcheck.mdc`
2. Write `docs/smellcheck.md` (pronouns, terms that pass here, protected lines)
3. Optional: paste `rules/agents.md` into `AGENTS.md` or `CLAUDE.md`
4. When drafting a page, essay, note, ship post, filing, or paper, open that genre file
5. For a publish pass: paste `rules/core.md` plus the overlay, then `rules/audit.md` or `rules/claims.md`. Do not paste the prompt alone.

Overlay, files, and Node: [docs](/docs/install).
