---
title: Don't copy the bans into every repo
date: 2026-08-13
description: Core is the house law. Genre files and project overlays add surface law. Copies diverge.
tags: [workflow]
---

The failure mode is a style guide that gets pasted into six repos, then edited in one of them on a Thursday.

aiBreze keeps one core. Genre files (`essays`, `landing`, `outreach`, `launch`) point at it, then write only what that surface adds. A consuming project keeps a short overlay: pronouns, terms of art that pass here, protected lines. It does not restate the escalation ban.

If a term names a real part of the work, leave it. The overlay lists the usual ones. The heuristic is the rule; the list is not exhaustive.

When you fork `core.md` into the repo "so the agent has it locally," you have started a second canon. Six months later nobody knows which file wins.
