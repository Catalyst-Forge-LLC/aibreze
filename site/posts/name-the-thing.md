---
title: Name the thing
date: 2026-08-17
description: Cover the heading. If you cannot tell what the section is, rename it.
tags: [workflow]
---

I wrote a heading I liked, then covered the paragraph. The heading said nothing you could act on. It sounded finished. It was a riddle.

The test is that cheap. Cover the body. If the label does not say which thing this is, name the thing. The clever line can stay in the prose if it earns a place there.

A sentence can fail the same way. "This is meant to live on a desktop you already leave on" sounds like a product. "Run it on a computer you leave turned on" is something you can say back.

I now write the heading after the paragraph, or I write a boring noun first and only then see if a sharper line is still a name.
